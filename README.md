# نظام العهدة

صفحة ويب لإدارة العهدة النقدية للموظفين، تعمل على الموبايل والكمبيوتر.

## ماذا يفعل

- **الموظف** يكتب اسمه عند أول دخول، ثم يسجّل العهدة المستلمة بتاريخها.
- **يضيف الفواتير:** التاريخ، ورقم الفاتورة (اختياري)، والبيان، والمبلغ بدون ضريبة.
  - إذا اختار «بها ضريبة» تُحسب ضريبة القيمة المضافة 15% تلقائيًا، وإذا اختار «بدون ضريبة» تكون الضريبة صفرًا.
- **يرفق صورة الفاتورة** من الكاميرا مباشرة أو يختار ملفًا.
- **الباقي من العهدة** يُحسب تلقائيًا بعد كل فاتورة.
- **المحاسب (صاحب الصفحة)** يرى عُهد كل الموظفين، ويحذف القيود عند الحاجة.
- **كشف حساب** يُعرض داخل الصفحة أو يُنزَّل PDF أو Excel:
  - أعمدة مدين (عهدة مستلمة) ودائن (مصروف) والصافي.
  - في آخر الكشف مكان توقيع الموظف والمدير المالي.

## التشغيل

الملف `index.html` منشور كصفحة (Artifact) على claude.ai، وهي التي توفّر حفظ البيانات وتخزين المرفقات وتنزيل الملفات وتحديد هوية المستخدم.

- **إذا فُتح الملف خارج claude.ai** يعمل في «وضع تجربة»، ولا تُحفظ البيانات.
- **صلاحيات البيانات المعلنة للصفحة:**
  - `custody`: يقرأها ويكتبها صاحب الصفحة فقط.
  - `custody/{self}`: كل موظف يقرأ ويكتب عهدته فقط.

## المكتبات

تُحمَّل عند الحاجة من cdnjs:

- `xlsx@0.18.5` لملفات Excel.
- `html2canvas@1.4.1` و`jspdf@2.5.1` لملفات PDF.
